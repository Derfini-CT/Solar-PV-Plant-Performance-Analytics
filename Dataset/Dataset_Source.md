\# 📊 Dataset Source



\## Dataset Name



BR-PVGen — Brazilian Photovoltaic Power Generation Dataset



\## Source



The dataset is publicly available through Zenodo:



https://zenodo.org/records/21511487



\## Dataset Description



BR-PVGen is a photovoltaic power generation dataset containing inverter-level electrical measurements and meteorological measurements from solar PV plants in Brazil.



The dataset is used in this project to analyze solar energy generation, plant performance, weather conditions, and photovoltaic system efficiency.



\## Data Period



March 26, 2024 to June 9, 2025



\## Sampling Resolution



15-minute intervals



\## Number of PV Plants



51 solar PV plants



\## Main Data Categories



\### Inverter Data



The inverter dataset contains measurements such as:



\- Datetime

\- Inverter ID

\- Plant ID

\- Total Active Power

\- Total DC Power

\- Total Reactive Power



\### Meteorological Data



The meteorological dataset contains:



\- Global Horizontal Irradiance (GHI)

\- Global Rear Irradiance (GRI)

\- Plane of Array (POA) Irradiance

\- Ambient Temperature

\- Panel Temperature

\- Precipitation

\- Wind Speed

\- Wind Direction

\- Tracker Albedo Index



\### Plant Metadata



The metadata contains:



\- Brazilian State

\- Plant ID

\- Nominal Power

\- Number of Panels

\- Panel Area

\- Panel Bifaciality

\- Panel Efficiency

\- Panel Temperature Coefficient

\- Structure Type

The dataset was used to build a Power BI dashboard for:
